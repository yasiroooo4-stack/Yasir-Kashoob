# ZKTeco Fingerprint Sync Manager
# مدير مزامنة أجهزة البصمة ZKTeco

## 📦 محتويات الحزمة

| الملف | الوصف |
|-------|-------|
| `sync_manager_gui.py` | **تطبيق سطح المكتب** - واجهة رسومية سهلة |
| `network_sync.py` | مزامنة عبر الشبكة (بدون ملفات MDB) |
| `sync_agent.py` | مزامنة ملفات MDB |
| `config_sample.json` | ملف تكوين نموذجي |

---

## 🚀 البدء السريع

### 1. تثبيت المتطلبات
```bash
pip install requests pyzk
```

### 2. تشغيل التطبيق الرسومي
```bash
python sync_manager_gui.py
```

## 📡 الاتصال المباشر بالشبكة (network_sync.py)

للاتصال مباشرة بأجهزة ZKTeco عبر الشبكة (بدون ملفات MDB):

### اختبار الاتصال بجهاز:
```bash
python network_sync.py --test 192.168.1.100
```

### مزامنة مرة واحدة:
```bash
python network_sync.py --config config.json
```

### تشغيل كخدمة مستمرة:
```bash
python network_sync.py --daemon --config config.json
```

---

## 📁 مزامنة ملفات MDB (sync_agent.py)

إذا كنت تفضل استخدام ملفات MDB:

```bash
python sync_agent.py --mdb C:/ZKTeco/att2000.mdb -u yasir -p password
```

## ⚙️ ملف التكوين (config.json)

```json
{
  "api_url": "https://milk-erp-1.preview.emergentagent.com",
  "username": "yasir",
  "password": "your_password",
  "sync_interval": 3600,
  "devices": [
    {
      "name": "جهاز البصمة الرئيسي",
      "ip": "192.168.1.100",
      "port": 4370,
      "location": "المدخل الرئيسي"
    }
  ],
  "mdb_paths": [
    "C:/ZKTeco/att2000.mdb"
  ]
}
```

## 🔧 استكشاف الأخطاء

### فشل الاتصال بالجهاز
1. تأكد من أن الجهاز متصل بالشبكة
2. تحقق من عنوان IP والمنفذ (4370 افتراضياً)
3. تأكد من عدم وجود جدار حماية يمنع الاتصال

### خطأ في المصادقة
1. تحقق من اسم المستخدم وكلمة المرور
2. تأكد من صحة عنوان API

### مكتبة pyzk غير موجودة
```bash
pip install pyzk
```

### مكتبة tkinter غير موجودة (Linux)
```bash
sudo apt-get install python3-tk
```
