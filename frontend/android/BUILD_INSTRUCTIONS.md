# دليل بناء تطبيق المروج للتتبع (Android APK)

## المتطلبات:
1. Android Studio (تحميل من: https://developer.android.com/studio)
2. Java JDK 11 أو أحدث

## خطوات البناء:

### 1. تحميل مجلد المشروع
- قم بتحميل مجلد `/app/frontend/android` بالكامل

### 2. فتح المشروع في Android Studio
- افتح Android Studio
- اختر "Open an existing project"
- اختر مجلد `android` الذي تم تحميله

### 3. انتظار تحميل المشروع
- Android Studio سيقوم بتحميل dependencies تلقائياً
- قد يستغرق هذا بضع دقائق

### 4. بناء APK
- من القائمة: Build → Build Bundle(s) / APK(s) → Build APK(s)
- انتظر اكتمال البناء
- ستجد ملف APK في: `android/app/build/outputs/apk/debug/app-debug.apk`

### 5. تثبيت التطبيق على الهاتف
- انقل ملف APK للهاتف
- افتح الملف واضغط "تثبيت"
- قد تحتاج لتفعيل "تثبيت من مصادر غير معروفة" في الإعدادات
