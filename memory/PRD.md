# نظام ERP لمزرعة الألبان - PRD

## نظرة عامة
نظام ERP متكامل لإدارة مزرعة الألبان يشمل:
- إدارة الموردين واستلام الحليب
- إدارة الموارد البشرية والرواتب
- إدارة المبيعات والعملاء
- النظام المالي والخزينة
- إدارة المستودعات المتكاملة
- نظام التنبيهات الذكي

## Tech Stack
- **Frontend:** React + Vite + Tailwind CSS + Shadcn/UI
- **Backend:** FastAPI (Python)
- **Database:** MongoDB
- **Languages:** Arabic (primary) + English

## API Endpoints

### طلبات الإجازة
```
GET    /api/hr/leave-requests              - قائمة الطلبات
POST   /api/hr/leave-requests              - إنشاء طلب جديد
PUT    /api/hr/leave-requests/{id}/approve - الموافقة على طلب
PUT    /api/hr/leave-requests/{id}/reject  - رفض طلب
```

### استلام الحليب
```
GET    /api/milk-receptions              
POST   /api/milk-receptions              
PUT    /api/milk-receptions/{id}         - تعديل
DELETE /api/milk-receptions/{id}         - حذف
POST   /api/milk-receptions/import       - استيراد
```
