# نظام ERP لمزرعة الألبان - PRD

## نظرة عامة
نظام ERP متكامل لإدارة مزرعة الألبان يشمل:
- إدارة الموردين واستلام الحليب
- إدارة الموارد البشرية والرواتب
- إدارة المبيعات والعملاء
- النظام المالي والخزينة
- إدارة المستودعات المتكاملة مع النظام المالي
- نظام التنبيهات الذكي للمخزون
- نظام الموافقة على البدلات الإضافية

## Tech Stack
- **Frontend:** React + Vite + Tailwind CSS + Shadcn/UI
- **Backend:** FastAPI (Python)
- **Database:** MongoDB
- **Languages:** Arabic (primary) + English

## هيكل الصفحات الجديد

### صفحة التقارير (`/reports`)
| التبويب | المحتوى |
|---------|---------|
| الموردين | تقارير الموردين والموازين |
| التوريدات | تقارير استلام الحليب |
| المالية | التقارير المالية |
| الرواتب | تقارير الرواتب |
| الحضور | تقارير الحضور والغياب |
| **متقدمة** | مقارنة الرواتب، التقرير المالي الشهري، أداء المراكز، تنبيهات المخزون |

### صفحة إعدادات النظام (`/system-settings`)
| التبويب | المحتوى |
|---------|---------|
| المراكز | إدارة مراكز التجميع |
| الأسعار | أسعار الحليب |
| الأعلاف | أنواع الأعلاف |
| التنبيهات | إعدادات التنبيهات |
| **المظهر** | الثيم، الملف الشخصي، كلمة المرور، سجل النشاط |
| **الإشعارات** | إعدادات SMS، جدولة التقارير |
| **الكاميرات** | نظام Hikvision CCTV |

## API Endpoints

### البدلات الإضافية
```
GET  /api/hr/attendance/pending-extra-pay           # جلب طلبات البدلات المعلقة
POST /api/hr/attendance/{id}/approve-extra-pay      # الموافقة على طلب
POST /api/hr/attendance/{id}/reject-extra-pay       # رفض طلب
POST /api/hr/attendance/bulk-approve-extra-pay      # الموافقة الجماعية
```
