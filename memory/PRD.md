# نظام المروج للألبان - PRD

## ملخص المشروع
نظام متكامل لإدارة شركة ألبان يشمل:
- إدارة الموردين والاستلام
- نظام تتبع مواقع الموظفين
- بوابة تسجيل الموردين الجدد
- إدارة الموارد البشرية
- إدارة المخزون والمالية

## الميزات المُنجزة

### ✅ نظام تتبع الموظفين (مكتمل)
- خريطة تفاعلية تعرض مواقع الموظفين باستخدام Leaflet.js
- علامات مخصصة تظهر:
  - الحرف الأول من اسم الموظف في دائرة ملونة
  - اسم الموظف المختصر
  - رقم الهوية/كود الموظف
- تلوين حسب الحالة (أخضر: داخل النطاق، أحمر: خارج النطاق)
- تنبيهات تلقائية عند خروج الموظف من نطاق العمل
- سجل حضور مبني على الموقع

### ✅ بوابة تسجيل الموردين (مكتمل)
- صفحة عامة لتسجيل الموردين الجدد
- دعم ثنائي اللغة (عربي/إنجليزي) مع زر تبديل
- نموذج يشمل: الرقم المدني، الهاتف، نوع الحليب، الكمية
- رفع المستندات (PDF, صور)
- إيصال "قيد المراجعة" قابل للطباعة
- لوحة تحكم للإدارة لفتح/إغلاق التسجيل

### ✅ تحديث واجهة المستخدم (مكتمل)
- تغيير اللون الرئيسي للبني الفاتح (#8B5A2B)
- شعار الشركة الجديد "المروج للألبان"

### ✅ إصلاح طباعة طلبات الإجازة (مكتمل)
- عرض حالة الطلب (موافق/مرفوض/قيد الانتظار) في المستند المطبوع

## البنية التقنية

### Backend
- **إطار العمل:** FastAPI (Python)
- **قاعدة البيانات:** MongoDB
- **المسارات الرئيسية:**
  - `/api/tracking/*` - نظام التتبع
  - `/api/supplier-registration/*` - بوابة الموردين
  - `/api/hr/*` - الموارد البشرية

### Frontend
- **إطار العمل:** React
- **المكونات:** Material-UI, Shadcn/UI
- **الخرائط:** Leaflet.js

### الملفات الرئيسية
```
/app/frontend/src/
├── components/
│   └── EmployeeTrackingAdmin.jsx   # خريطة التتبع
├── pages/
│   ├── EmployeeApp.jsx             # تطبيق الموظفين
│   ├── SupplierRegistration.jsx    # تسجيل الموردين
│   └── SystemSettings.js           # إعدادات النظام

/app/backend/routes/
├── tracking_routes.py              # APIs التتبع
└── supplier_registration_routes.py # APIs الموردين
```
