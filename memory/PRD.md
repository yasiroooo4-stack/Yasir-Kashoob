## APIs بوابة الموردين
- `POST /api/supplier-portal/login` - تسجيل دخول بكلمة مرور
- `POST /api/supplier-portal/recover-password` - استرجاع كلمة المرور
- `PUT /api/supplier-portal/change-password` - تغيير كلمة المرور
- `GET /api/supplier-portal/milk-receptions` - توريدات الحليب
- `POST /api/supplier-portal/feed-requests` - طلب أعلاف
- `GET /api/supplier-portal/messages` - الرسائل
