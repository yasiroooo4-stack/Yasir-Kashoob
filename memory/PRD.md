  - سبب العذر، رابط المرفق، ملاحظات
- **سير العمل:**
  - الموافقة → تسجيل حضور تلقائي
  - الرفض → تسجيل غياب
- **تبويب "الأعذار"** في صفحة الموارد البشرية
- **APIs جديدة:**
  - `POST /api/hr/excuse-requests` - إنشاء طلب
  - `GET /api/hr/excuse-requests` - جلب الطلبات
  - `PUT /api/hr/excuse-requests/{id}/approve` - موافقة
  - `PUT /api/hr/excuse-requests/{id}/reject` - رفض
  - `DELETE /api/hr/excuse-requests/{id}` - حذف
