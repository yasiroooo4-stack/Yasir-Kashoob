# نظام ERP مركز تجميع الحليب - المروج للألبان

## المشكلة الأصلية
نظام ERP شامل لمركز تجميع الحليب (المروج للألبان) يشمل:
- إدارة الموردين والمزارعين
- الموارد البشرية والرواتب
- المالية والخزينة
- المخزون والمبيعات
- بوابة الموردين
- **تطبيق موبايل للموردين**

---

## ما تم تنفيذه - 5 يناير 2026

### ✅ تطبيق الموبايل للموردين (React Native/Expo)
**المسار:** `/app/mobile-app/supplier-app/`

#### الشاشات المُنفذة:
1. **شاشة تسجيل الدخول** (`LoginScreen.js`)
   - تسجيل بكود المورد + كلمة المرور (0000)
   - واجهة عربية RTL

2. **لوحة التحكم** (`DashboardScreen.js`)
   - عرض الرصيد الحالي
   - إحصائيات التوريدات
   - آخر التوريدات
   - أزرار الوصول السريع

3. **طلب أعلاف** (`FeedRequestScreen.js`)
   - اختيار نوع العلف (شعير، نخالة، ذرة، برسيم، مخلوط)
   - اختيار الكمية
   - حساب المبلغ التلقائي
   - إرسال الطلب للموافقة

4. **سجل التوريدات** (`SuppliesScreen.js`)
   - عرض جميع التوريدات
   - تفاصيل كل توريدة

5. **إرسال رسالة** (`MessagesScreen.js`)
   - أنواع الرسائل المختلفة
   - إرسال للإدارة

6. **الإعدادات** (`SettingsScreen.js`)
   - معلومات الحساب
   - تغيير كلمة المرور
   - تسجيل الخروج

---

### ✅ تحسينات أخرى
- كلمة مرور 0000 لجميع الموردين (1143 مورد)
- إصلاح أرقام الموظفين المفقودة (5 موظفين)
- نظام موافقة المدير على نقل/تعديل الموردين
- دمج منطق الإجازات في الرواتب (العطل 2x، الإجازة الأسبوعية 1.5x)
- تحسين صفحة إدارة الموردين

## كيفية تشغيل تطبيق الموبايل

```bash
cd /app/mobile-app/supplier-app
npm install
npx expo start
```

ثم:
1. حمّل تطبيق **Expo Go** على هاتفك
2. امسح QR code من Terminal
3. سيفتح التطبيق

### بناء APK للأندرويد:
```bash
npm install -g eas-cli
eas login
eas build --platform android --profile preview
```
