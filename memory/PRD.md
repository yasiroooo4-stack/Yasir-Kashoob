# نظام ERP مركز تجميع الحليب - PRD

## المشكلة الأصلية
نظام ERP كامل لمركز تجميع الحليب يشمل جميع الأقسام

## المستخدمين المستهدفين
- **المدير (Admin)**: صلاحيات كاملة على جميع الأقسام
- **الموظف (Employee)**: إدارة الموردين، استلام الحليب، المبيعات، المخزون
- **المحاسب (Accountant)**: إدارة المالية والدفعات والتقارير

## ما تم تنفيذه

### 4 يناير 2026 - تحديثات مشتريات الأعلاف والمزامنة

#### 1. تنبيهات انخفاض مخزون الأعلاف ✅
- شريط تنبيه برتقالي يظهر عند انخفاض المخزون عن الحد المحدد
- عمود "الحد الأدنى" في جدول أنواع الأعلاف مع زر 🔔
- مستويات: حرج (نفذ) / تحذير (منخفض)
- APIs: `GET /api/feed-inventory/alerts`, `PUT /api/feed-types/{id}/min-stock`

#### 2. إصلاح مشكلة مزامنة البصمة ✅
- تعديل API `/api/hr/attendance` لإرجاع `409 Conflict` للسجلات المكررة
- إضافة API جديد `/api/hr/attendance/upsert` للمزامنة مع دعم التحديث

#### 3. صفحة طباعة طلب الشراء (Purchase Request) ✅
- تصميم مطابق للنموذج المطلوب
- دعم ثنائي اللغة (عربي/إنجليزي)
- يعرض جميع أنواع الأعلاف مع الكميات
- ملاحظات وتعليمات للمربين
- قسم التوقيع والتاريخ
- API: `GET /api/feed-purchases/{id}/print` (PDF)

#### 4. ربط مشتريات الأعلاف بالمخزون والمالية ✅
- إضافة تلقائية للمخزون
- تسجيل في الخزينة
- تقارير شاملة
